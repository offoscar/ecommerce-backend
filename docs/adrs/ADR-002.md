# ADR-002: Estructura del repositorio.

## Creador
Oscar Rueda.

## Contexto
Debemos definir la organización del código fuente para MangaShop, dividiendo la interfaz de usuario desarrollada en React del servidor de API REST desarrollado en Node.js/Express[cite: 1].

## Decisión
Mantendremos dos repositorios totalmente SEPARADOS: un repositorio para el backend y otro independiente para el frontend[cite: 1].

## Consecuencias
+ Aislamiento completo de dependencias, scripts de build y registros de commits entre cliente y servidor[cite: 1].
+ Toda la documentación técnica del servidor y del dominio (`/docs/diagrams/` y `/docs/adrs/`) se centraliza de manera ordenada en el repositorio backend[cite: 1].
- Requiere que los desarrolladores clonen, configuren y mantengan dos proyectos independientes en su entorno local de trabajo.
