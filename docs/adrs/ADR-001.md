# ADR-001: Base de datos del proyecto.

## Creador
Oscar Rueda.

## Contexto
MangaShop requiere almacenar un catálogo amplio de mangas, editoriales, categorías, stock de proveedores, usuarios, empleados y el historial completo de pedidos. Necesitamos un modelo de datos flexible que permita escalar la estructura del catálogo sin realizar migraciones complejas de esquemas.

## Decisión
Aadoptaré MongoDB como base de datos principal desplegada en un contenedor gestionado con Docker.

## Consecuencias
+ Permite embeber documentbos (como direcciones o líneas de pedido dentro del historial) o referencias flexibles entre entidades.
+ Excelente integración con el ecosistema de Node.js / Express mediante Mongoose.
- Requiere controlar la consistencia y relaciones entre documentos a nivel de lógica de aplicación, al no contar con integridad referencial nativa rígida tipo SQL.
